# Temp Mail SaaS

Greenfield product architecture on an existing Laravel scaffold. Current delivery is Phase 0 documentation only; product features are planned, not implemented.

Start with [AGENTS](AGENTS.md), [documentation index](docs/README.md), [architecture](docs/architecture.md), [decision register](docs/decisions.md) and [Phase 0 audit](docs/phase-0-audit.md).

Approved direction: Laravel 13, compatible PHP, Blade, Tailwind, Alpine.js, Vite and MySQL; English first with multilingual/RTL readiness. Phase 1 needs explicit approval. No setup commands should be run from historical reports.

Intended GitHub repository: https://github.com/sufiralight/temp-mail. The inspected folder is not a Git checkout. Commit requires the user's final confirmation; no push is authorized.
