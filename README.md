# Temp Mail SaaS

Laravel 13 / Blade / Tailwind / Alpine CSP / Vite / MySQL 8.4. Current delivery: Phase 1 foundation and a private four-step installer. Full authentication, dashboards, CMS, temporary mail and billing are deferred.

Read [AGENTS](AGENTS.md), [documentation owners](docs/README.md), [operations/setup](docs/operations.md), [installer trust model](docs/installation.md) and [actual test results](docs/testing.md). Existing .env, APP_KEY and database data must be preserved.

Installer access is disabled by default. An operator must verify a loopback-only local listener or restricted production SSH tunnel before provisioning it. Hosting/SSH availability remain production prerequisites. No Setup Credential screen or installer password exists.

Git origin: https://github.com/sufiralight/temp-mail. Phase 0 was pushed as 4a9a2d7. Phase 1 commit/push require the user's requested final confirmation.
