# Frontend

Own Blade APIs and progressive enhancement. Use semantic tokens and vanilla JavaScript. Escape output and preserve native form semantics and CSRF protection.

Verify keyboard, responsive, RTL and both theme behaviors.

Read [components](../docs/components.md) and [accessibility](../docs/accessibility.md) before changes.

Use the existing appearance API and initialize it in the document head before styles. Keep theme choices independent of page navigation and preserve keyboard focus.
