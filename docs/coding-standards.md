# Coding standards

Use typed PHP 8.5 signatures and descriptive names. Follow Laravel conventions and format changed PHP using Pint. Use named routes, Form Requests for server-side validation, policies for authorization, parameterized persistence, and environment values through Laravel config files. Escape Blade output and require CSRF protection for browser writes.

Use consistent Blade props and slots. Keep Tailwind 4 tokens centralized and use vanilla JavaScript with progressive enhancement. Keep behavior modular and avoid framework dependencies and unnecessary abstractions.

Use PHPUnit feature tests for request behavior and regressions and unit tests for isolated logic. Prove denied paths and use isolated test data. Review data migrations for compatibility, locking, and recovery. Review accessibility, responsive behavior, and deployment impact alongside functional behavior. Update affected documentation in the same change.
